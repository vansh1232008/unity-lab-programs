Unity Lab Programs

Programs P1 to P5 as one Unity project.

Download ZIP330 KB

How to open

  1. Unzip the file.
  2. Open Unity Hub → Projects → Add → Add project from disk.
  3. Select the Unity_Lab_Programs folder and open it (Unity 2021.3 or newer).
  4. Go to Assets → Programs → P1 (or P2–P5), double-click the scene, press ▶ Play.

Programs

  • P1 Cube, Plane, Sphere: move at different speeds, rotate on X/Y/Z and scale in different directions (geoTransform)
  • P2 UI menu (Canvas, Images, Sprites, Buttons) controlling two animated characters, with the "win" trigger
  • P3 First Person Controller on a terrain with textures, trees, Wind Zone and rain
  • P4 2D Ray-caster: finds the target and gives hit, distance and position; the parachute opens automatically
  • P5 Marker-based AR: detects a marker and places a model on it
